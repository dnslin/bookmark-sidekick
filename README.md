# 拾签 · Bookmark Sidekick

一个放在 Chrome 侧边栏里的个人书签助手。

它会读取你现有的 Chrome 书签，方便你收藏、搜索和整理网页。你也可以接入自己的 AI 接口，让它生成分类、标签和摘要建议。

## 功能

- 在 Chrome 侧边栏查看和搜索书签
- 收藏当前网页，并显示网站图标
- 使用 AI 生成分类、标签和摘要建议
- 建议确认后才会应用
- 保存网页正文，方便以后阅读
- 检查网页是否还能访问
- 导出和恢复模型配置、分类、书签信息与网页快照

AI 功能不是必需的。不配置模型时，仍然可以使用基础的书签浏览、搜索和收藏功能。

## 安装

### 使用发布包

1. 在仓库的 Releases 页面下载最新的 Chrome 压缩包。
2. 解压下载的文件。
3. 在 Chrome 打开 `chrome://extensions`。
4. 开启右上角的“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择刚才解压的目录。

### 从源码构建

需要 Node.js 22.16 或更高版本。

```bash
npm install
npm run build
```

构建完成后，在 Chrome 中加载：

```text
.output/chrome-mv3
```

## 使用

1. 点击扩展图标，打开侧边栏。
2. 侧边栏会自动读取现有的 Chrome 书签。
3. 打开一个网页后，可以直接点击“收藏”。
4. 需要 AI 分类时，在设置中填写接口地址、API Key 和模型名称。
5. AI 生成的建议会出现在“待确认”中，由你决定是否应用。

拾签中的分类只用于扩展自己的整理视图，不会移动 Chrome 原有的书签文件夹。

## 备份与恢复

设置页面可以导出完整备份，内容包括：

- 模型配置
- 自定义分类
- 书签分类、标签和摘要
- 已保存的网页正文

恢复前会先显示备份内容概览，确认后才会写入。

备份文件中包含明文 API Key，请只保存在可信的位置。

## 数据说明

- 数据主要保存在当前浏览器中
- 没有配置并授权 AI 时，不会向模型发送书签内容
- 使用 AI 时，书签标题、网址、文件夹和已保存正文会发送到你填写的模型接口
- 卸载扩展会清除拾签保存的分类和网页快照，但不会删除 Chrome 原有书签
- 在拾签中执行“删除书签”会同时删除对应的 Chrome 原生书签
