# Chrome 手动验收清单

状态：未执行。应先在独立 Chrome 测试配置文件中运行，不使用主浏览器书签。

## 准备

导入十几个普通书签，包含同网址不同文件夹的两条书签、无标题书签、带 utm 参数的链接、一个 chrome:// 链接。运行 `npm install && npm run check`，加载 `.output/chrome-mv3`。

## 界面与书签

- [ ] 扩展图标打开侧边栏，不弹新页面；300 / 360 / 420px 宽度不出现水平溢出。
- [ ] 浅色/深色、键盘 Tab 聚焦均可使用。
- [ ] 首次自动读取书签；Chrome 目录结构、标题、URL 无变化。
- [ ] 搜索能匹配标题、URL、摘要、标签和分类。
- [ ] 切换当前页，收藏区更新；已收藏页面显示「已收藏」。
- [ ] 收藏一篇文章：拒绝站点权限仍保存链接；允许权限时保存阅读快照。
- [ ] 快速连续点击收藏，不产生重复书签。
- [ ] 在 Chrome 原界面改名、移动、删除书签，侧边栏更新并清理对应过期数据。

## 分类确认

- [ ] 未配置/未授权时，不向任何模型发送书签。
- [ ] 填入自己的接口并「测试连接」，确认错误模型名、错误 Key、限流都有可理解提示。
- [ ] 保存授权配置后，未分类书签开始生成建议；分类页仍不出现未确认结果。
- [ ] 按分类或「需检查」筛选、修改建议，点击确认只应用当前列表。
- [ ] 原生 Chrome 文件夹始终不动。
- [ ] 分类建议生成后，在 Chrome 修改同一书签的 URL 或标题，旧建议失效。
- [ ] 分析时手动修改分类，晚到的模型结果不覆盖手动选择。
- [ ] 模型返回非法分类、重复/缺失 ID 或非 JSON 时，不应用任何该批次结果。

## 任务恢复

- [ ] 关闭并重开侧边栏，已完成建议仍在。
- [ ] 从扩展 Service Worker 调试页面停止 Worker，等待租约过期后后台可继续处理。
- [ ] 暂停后当前批次允许完成，但不再领取下一批。
- [ ] 错误后停止继续调用；「重试失败项」重新处理，已成功结果不被清空。
- [ ] 浏览器关闭后重新打开，恢复待处理任务。

## 快照与状态

- [ ] Readability 无法提取的工具页面仍可收藏，不伪造正文。
- [ ] 快照显示精简正文，无网页脚本、图片、外部 iframe。
- [ ] 快照中链接在新的普通标签页打开，不替换侧边栏。
- [ ] HEAD 不支持时可用 GET 检查；404/410 与 403/429/500、超时显示不同状态。
- [ ] 已检查为失效且有快照的书签打开本地阅读正文。
- [ ] 没有保存过正文的旧失效链接，不出现虚构恢复结果。

## 数据

- [ ] 备份不包含模型地址或 API Key。
- [ ] 在另一测试配置文件中导入原生书签后，恢复备份按 URL/原文件夹匹配，而不是沿用旧 ID。
- [ ] 备份中无法匹配的书签显示为跳过，不创建或删除原生书签。
- [ ] 删除前明确提示会删除 Chrome 原书签；取消时无变化。
